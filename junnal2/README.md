# Proyek Praktikum Sistem Pengolahan Digital

Proyek ini berisi analisis karakteristik sinyal dasar dan aplikasi pengolahan sinyal menggunakan Python.

## Isi Direktori
- **pengaruh_alpha_eksponensial.ipynb**: Jupyter Notebook utama yang berisi seluruh eksperimen, kode, dan visualisasi untuk presentasi.
- **audio_naik.wav**: Contoh sinyal audio dengan karakteristik tertentu (digunakan untuk analisis di notebook).
- **audio_turun.wav**: Contoh sinyal audio dengan karakteristik tertentu (digunakan untuk analisis di notebook).
- **WhatsApp Ptt 2026-03-16 at 17.01.32.wav**: Rekaman suara WhatsApp terkait materi.

## Panduan Presentasi
1. Jalankan `pengaruh_alpha_eksponensial.ipynb` menggunakan Jupyter Lab atau VS Code.
2. Pastikan library `numpy`, `matplotlib`, `scipy`, dan `sounddevice` sudah terinstal.
3. Notebook sudah dilengkapi dengan penjelasan teori pendukung untuk memudahkan penyampaian materi saat presentasi.
